## 🧑‍💻 &nbsp; About Me

Hey! I'm **Mubarek**, a Full Stack Developer based in **Addis Ababa, Ethiopia 🇪🇹**. I build web and mobile products end-to-end — from clean UI to scalable backend architecture.

I focus on **Web Apps**, **Mobile Apps**, and **SaaS Products**, and I'm always working on something new. Right now I'm building:

- 📘 **README Generator SaaS** — AI-powered, GitHub-integrated README builder
- 🛒 **DireMarket** — A student marketplace app built with React Native & Supabase
- 📱 **Cross-platform mobile apps** using Expo Router & NestJS

My go-to stack spans **React / Next.js**, **React Native / Expo**, **NestJS**, **PostgreSQL**, **Supabase**, and **Docker** — and I'm always learning what comes next.
